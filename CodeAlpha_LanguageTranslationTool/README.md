# Smart Language Translator 🌍

This is a modern, responsive Language Translation Tool built as **Task 1** for the **CodeAlpha Artificial Intelligence Internship**. 

It goes beyond basic translation by integrating voice recognition, text-to-speech, and a stunning Glassmorphism UI.

## ✨ Innovative Features
* **Stunning UI:** Modern glassmorphism design with animated gradients for a premium feel.
* **Voice Input (Speech-to-Text):** Users can dictate their sentences using the browser's native Web Speech API.
* **Audio Playback (Text-to-Speech):** Hear the translated text pronounced in the target language's accent.
* **1-Click Copy:** Easily copy translations to the clipboard.
* **Optimized API Calls:** Uses the MyMemory Translation API for fast, reliable translations.

## 🛠️ Technologies Used
* **Frontend:** HTML5, CSS3 (Vanilla), JavaScript (ES6)
* **Design:** CSS Glassmorphism, FontAwesome Icons
* **APIs:** 
  * MyMemory Translation API
  * Web Speech API (SpeechRecognition & SpeechSynthesis)
  * Clipboard API

## 🚀 How to Run Locally
1. Clone this repository to your local machine.
2. Open the project folder in VS Code.
3. Use the **Live Server** extension to launch `index.html`.
4. Allow microphone permissions if you wish to test the voice input feature.
